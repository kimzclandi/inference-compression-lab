# 简历候选条目：个人项目与 NUSRI 经历分开

## 当前个人项目：MiniLM 模型量化与 CPU 推理优化

当前可用的透明版本：

- 在 AI 辅助下基于 ONNX Runtime 官方 API 构建 MiniLM 动态 INT8 评测与推理模块，比较量化粒度及36个 MatMul 的局部误差，结合 profiler 核验真实 CPU 整数执行。
- 通过线程配置对照和独立请求复验，将 M4 Max 上 batch=1、长度64的按通道 INT8 推理延迟从2.261 ms降至1.933 ms（约14.5%）；模型文件缩小35.0%，在冻结配置后首次评测的1,379对 STS-B test 上，Spearman 相对FP32下降0.00155。

可选的技术亮点句（适合面试展开，不必全部塞入简历）：

- 验证量化收益随输入形状变化：同为8线程，长度16负载下INT8纯推理延迟较FP32降低约9.0%；匹配batch=1/长度16的973对无截断短句质量子集，Spearman下降0.00260。长序列负载仍慢于FP32，保留负结果。

如果简历很紧，优先保留前两条。不要把“4→8线程的14.5%改善”写成“量化本身带来14.5%加速”。完整test质量最长256、batch16与长度64计时不是同一负载；面试时必须解释。
