## 本轮新验证和历史证据

新验证记录均在 [independent-review-v1](../results/independent-review-v1)。对审查基线的全部 698 个结果文件逐字节核对，零修改；其中历史发布清单保护的 628 个文件也保持不变。

- **统计独立实现**：不导入项目评分或统计模块，从全部 640 条原始预测重算 EM/F1、逐题类别与三组 bootstrap 比较；核对原始 SQuAD 文件并独立重建 128 题及四篇文章选择。逐项匹配。
- **真实张量独立读取**：直接解析 safetensors，核对五个模型全部张量和完整文件清单；用 NumPy 独立将原始 BF16 的 290 个张量转为 FP16，比对全部字节摘要。两个回退模型各 12 个 block 张量与原始 FP16 相同，其他张量与 Q4 相同。没有把反量化当恢复。两者总张量成本均为 299,428,608 bytes，较 Q4 多 21,432,320 bytes；文件容器头大小不同不影响等张量成本。
- **真实推理独立循环**：按每篇文章、每种可回答性字典序首 ID 固定 8 题，五变体共 40 条生成；在无 Git 源码目录用另一份 greedy 循环运行，prompt、token、文本、首 token top10 全部匹配。没有选择“最好复现”的样本，也不是新确认。
- **历史性能独立重算**：独立脚本读取 188 个文件，不调用实验汇总函数，核对 MiniLM、Qwen 公平基线、生命周期和量化性能。没有新报速度数字。
- **可追溯时序**：七个冻结输入/runner 与 `5ca4191` 一致；提交记录早于确认开始 36.15 秒。这支持保存的时序，不证明不存在未记录试跑或构成外部预注册。
- **环境边界**：本轮复用上轮固定 Python 3.12.11 / MLX 0.29.3 / MLX-LM 0.26.3 环境，M4 Max 48 GiB。上轮新环境安装、五模型重建和全部 640 生成属于历史证据，经本轮交叉核对；不再次声称本轮全新安装或全量重跑。

## 确认负结果及解释

|变体|EM 正确数|F1|
|---|---:|---:|
|FP16|33/128|0.325181|
|Q4|26/128|0.281002|
|Q8|34/128|0.329087|
|Q4 加 block10 FP16|29/128|0.283478|
|Q4 加 block22 FP16|25/128|0.275737|

block10 对 Q4 gain=3、loss=0，差 +2.34375 个百分点。按四篇文章分层、85 个精确 context 家族成组抽样，5000 次 bootstrap 的 95% 区间为 [0, 5.07246] 个百分点，下界不严格大于 0。相对 FP16 的 F1 下降 4.17027 个百分点，超出预设 2 点上限。因此预设合取门槛失败；不改门槛，也不能反向断言方法完全无效。

三道新增正确中，两道主要由完整解释句变成精确答案片段，另一道由数字 `4` 变成可接受的 `42`。因此不能统一写成事实推理恢复。normalized EM 与精确子串约束是不同指标；例如 Q4 的 EM=26 与类别 correct=24 可以同时成立，不能把 `format_valid` 当纯格式合规。

四篇文章来自公开 SQuAD dev，不是官方隐藏测试。只排除盘点内标题、ID、规范化精确 context/question；预训练污染和语义近重复未知，文章领域变化影响解释。文章分层未重采样文章，区间条件于这四篇文章。已公布数据以后复跑不再称未见确认集。

## 实现范围

框架提供量化/反量化算子、模型层、Metal/ORT kernels 和 KV 张量基础实现。项目实现前缀身份与复用边界、缓存生命周期和预算、直接分段公平基线、原始权重回退导出、诊断、轮换协议、独立评分和验收工具。代码与实验由 Codex 辅助完成。

不覆盖训练加速、分布式训练、蒸馏、稀疏、token 压缩、自研 Attention/kernel、激活或 KV 量化、FP8、功耗测量及生产部署。历史固定性能实验的范围与局限见对应报告。
