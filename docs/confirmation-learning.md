# 一个单元：为什么多答对三题仍未通过确认

领域地图：低比特量化改变权重，权重误差改变 logits，greedy 选择改变文本，任务评分判定可用性。旧单元解决“在哪个模块做干预”；本单元位于干预之后，解决“观察到的收益是否足以支持预先承诺的结论”。必须掌握固定对照、配对差和选择偏差；进阶是分组抽样与外推范围；暂不必学习复杂贝叶斯建模或所有显著性检验。

## 输入、输出与顺序

输入为同一128题上五个模型的预测，按ID一一配对。这里不操作模型张量；统计数组可以理解为 `[128, 5]`，每格是该问题在该变体下的0/1 EM。对比 selected 与 Q4，逐题相减得到 `[128]` 的差值：新增正确为+1、丢失正确为−1、其余为0。均值是3/128，不是相对百分比增长。

同一context可能有多个相关问题，不能默认各题独立。85个family按4个文章分组，每篇内有放回抽取原数量的family，带上family中的全部问题，计算这一轮配对差均值；做5000次，取固定排序位置得到95%区间。family大小不同，重采样的总题数可以变化，所以每轮必须用自己的题数作为分母。文章未被重采样，结论条件于这4篇文章。

## 五个思维模型

|模型|为什么与何时适用|失效边界；面试/工作用法|
|---|---|---|
|测量层级链条|logits、输出、评分、部署是不同层级；上游变化需要下游验证|不能凭margin修复宣称任务改善；逐层说明证据走到了哪里|
|选择与确认分离|在24个候选中选最优会利用样本偶然性；另固定数据检验|新集被反复调参就不再独立；先冻结，后运行，失败后不换名字|
|配对而非两个孤立均值|同一题难度相同可抵消，新增和丢失都要记录|不同输入/评分不可配对；回答净增3时同时给出gain3/loss0|
|相关性决定有效信息|同文段问题共享内容，family抽样保留组内关系|精确context仍不涵盖所有语义相关性；说明抽样单位与外推范围|
|验收是条件合取|方案要同时满足质量收益与可接受退化，不是挑一项好指标|门槛若事后改变就失去确认意义；按事先规则逐项报告pass/fail|

## 三项工程取舍

1. **逐题 bootstrap 或 family bootstrap。** 前者更简单，但默认独立题目可能低估相关性；后者保留同context关联，但85组仍不能代表所有文章。此处按family、文章分层，代价是结论更局限；并没有一个普遍最优的分组。
2. **确认集同域或新文章。** 同域有利于隔离量化干预，新文章有利于检查领域迁移但引入分布变化。本实验选择新文章，不能把失败全部归因于选层无效，也不能用领域变化抹掉未通过门槛的事实。
3. **追求更多恢复或控制资源代价。** 恢复更多层可能提高质量，也可能失去Q4成本优势。等张量成本对照帮助比较模块选择，但不保证相同延迟，且单层结果不能证明多层可线性叠加。此处先检验固定一层，不在确认集上追加层数搜索。

## 面试与故障定位

30秒回答：“我先在旧dev上用24个模块干预定位一个回退候选，再固定block10与等成本block22，在128题新文章样本上一次确认。回退比Q4多对3题，但按context分组的95%区间下界为0，F1相对FP16下降4.17个百分点，超过2点上限，因此我保留未通过结论。工程价值在可追溯的对照和诊断，不是宣称新量化算法。”

深入追问：为什么不能只看29和26？为什么区间下界0不是证明收益为0？为何四篇文章不能支持全领域结论？为什么模型文件哈希不同仍可能数值完全一致？

常见错误：“没有显著性所以方法无效”“95%概率真实参数在这一次区间里”“把test当dev改到通过”“始终拒答64题正确所以值得部署”。这些说法分别混淆证据不足与反证、频率学派区间解释、选择与确认、以及任务用途。

工程清单：先固定样本/模块/评分/门槛；核对ID覆盖与prompt一致；保留gain/loss；按依赖结构选择抽样单元；固定随机种子与百分位算法；保留F1和拒答表现；不把旧速度负载并入新质量实验；保留负结果与源代码身份。
