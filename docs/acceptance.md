# 验收清单

状态默认未验收。通过代码单元测试不代表模型实验完成。无正向收益也可通过实验完整性验收。

## 1. Transformer PTQ 数值实验

- [ ] 固定模型版本、浮点精度与任务，建立浮点/基础 PTQ/一种改进方法对照。
- [ ] 区分校准、选参、最终评测；保存数据清单或哈希。
- [ ] 明确位宽、量化轴、粒度、裁剪、静态/动态方式、浮点模块。
- [ ] 记录任务指标、逐层误差、失败样本。
- [ ] 完成一个有假设的消融；保持非研究变量一致。
- [ ] 明确 fake quant 与整数执行；明确使用官方实现/修改/独立实现。
- [ ] 保存环境、随机种子、运行命令、原始结果与结论边界。

## 2. 真实低精度后端

- [ ] 根据实际硬件和格式选择兼容后端，保存版本。
- [ ] 用执行图、日志或 profiler 核验算子精度与浮点回退；权重 dtype 不足以证明整数计算。
- [ ] 比较浮点、模拟量化（如有）与真实后端输出及任务指标。
- [ ] 固定硬件、batch、输入长度和计时范围；保存时延及峰值内存测量。
- [ ] 生成模型区分 prefill、decode、输入输出 token 数及实际生成长度。
- [ ] 解释实际观察到的收益或限制；未测的范围明确写未测。

已完成 CPU 粒度对照、128 句探针的逐层累计/同输入局部误差、单 MatMul 浮点回退消融、整数 profiler 核验及轮换计时。插桩偏差被发现并保留，优化后诊断通过最终输出一致性检查。完整证据见 [Mac 报告](../results/minilm-mac-m4max-baseline/REPORT.md)。
