# 固定回退模块的新样本确认：未通过门槛

研究问题：在六个 Q4 失败样本上选出的 decoder block 10 回退，是否在未参与筛选的新文章问题上仍比完整 Q4 与等成本 block 22 对照更好，同时保持 FP16 的 F1？这不是新的量化方法。

## 协议先于结果

协议、数据、选择规则与运行器在 `5ca4191ec0b25aeece4bbc9736d87175ce98c1cd` 提交后执行。保留原 greedy prompt、48-token 上限、EOS 停止和评分函数，不再扫描模块。FP16/Q4/Q8/selected/control 各运行一次，共 640 条模型生成；first-token diagnostics 另作单独 forward，不用于性能结论。

新样本来自公开 SQuAD 2.0 dev：4 篇文章各 32 题，可回答/不可回答各 16，共 128 题、85 个规范化精确 context 家族。排除已盘点旧数据的标题、ID、精确规范化 context/question；文章及问题以固定 seed 的哈希排序选择，不读取模型输出。此前未使用的文章带来领域变化；不是官方隐藏测试，预训练污染未知，语义近重复未排尽。全文筛选可从固定原始文件重建。

所有模型在 Apple M4 Max 48 GiB、macOS 27.0、Python 3.12.11、MLX 0.29.3 / MLX-LM 0.26.3 的**新建环境**，从同一 pinned upstream 在本地重建。五个变体的张量内容/形状/dtype、解析后的配置和 tokenizer 身份全部核对。Safetensors 的容器哈希允许不同，但不能用这一理由容忍张量变化。实际文件哈希仍保存。

推理从不含 `.git` 的源码归档执行，`run.json` 的 git_head 为 null，source 哈希与副本负责标识代码。原环境、原权重与历史证据未覆盖。随后补充检查全部八个 tokenizer/template/generation sidecar；五模型与原身份一致。

## 结果

|变体|归一化 EM|F1|format_valid|
|---|---:|---:|---:|
|FP16|33/128|0.325181|110/128|
|Q4|26/128|0.281002|82/128|
|Q8|34/128|0.329087|109/128|
|Q4 + block 10 原始 FP16|29/128|0.283478|92/128|
|Q4 + block 22 原始 FP16|25/128|0.275737|77/128|

format_valid 同时含“必须是原文精确子串”等要求，不等于人工认定的纯格式正确率。全部变体在 64 个不可回答问题上均未获得正确拒答；始终 NO_ANSWER 的基线为 64/128，优于全部变体总 EM。不能用作合格 QA 系统。

block 10 比 Q4 新增 3 个正确答案、丢失 0 个，配对 EM 差 +2.34375 个百分点；按文章分层、context 家族成组、有放回抽样 5,000 次，95% percentile 区间为 **[0, 5.07246] 个百分点**。下界未严格大于 0，预设的 Q4 比较门槛不通过。

相对 block 22，新增 4 个、丢失 0 个，差 +3.125 个百分点，区间 [0.74627, 6.29921]，通过这一项。相对 FP16 的 F1 下降 **0.04170275**，超过事先规定的 0.02。因此三个条件的合取为 **false**。区间只条件于这四篇文章，不代表所有领域；不能把区间包含零解释为已证明“完全无效”。

与旧 74 题探索相比，方向上仍有局部恢复，证据强度不够支撑已确认的质量收益。Q8 仍是值得保留的比较对象；它的一个样本 EM 超过 FP16 不证明普遍优于 FP16。没有修改评分、换样本、换层、扩大样本直到显著，或把确认数据重新称作未见集。

本轮不新增速度排名。原 8 个固定性能输入、32-token 输出、5 轮独立进程的资源/速度证据继续单独保留，不能和新 128 题拼成同一负载指标。

## 本轮发现并修复的问题

1. 旧验证器接受空 checksum 清单。以真实证据副本复现后，改为非空清单、精确文件覆盖、路径约束及逐文件哈希；评分与原始结果不变。哈希证明文件未意外漂移，不证明来源真实性或抵抗恶意重签全部数据。
2. 历史全量实验需要其他个人项目的缓存和 Git 元数据。新增本仓库模型重建入口，使用固定原始权重和张量身份验证；无 Git 源码归档真实推理通过。
3. 仅 tokenizer.json/config 不足以约束加载器外部 chat_template。新增八个 sidecar 检查，并从本轮保存的模型文件身份补充复核；无需重复推理或更改模型输出。
